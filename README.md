# Yamaha R1 Parallax Webpage

A beautiful parallax scrolling webpage showcasing the Yamaha R1 motorcycle with interactive elements and video backgrounds.

## Features

- **Parallax Scrolling**: Smooth parallax effects for immersive scrolling experience
- **Video Background**: Bike.mp4 video plays in the background of the "COOL!" section
- **Responsive Design**: Optimized for both desktop and mobile devices
- **Modern UI**: Clean, professional design with smooth animations

## Sections

1. **Hero Section**: Yamaha R1 introduction with parallax background
2. **About R1**: Detailed information about the motorcycle
3. **Less Weight**: Highlighting the bike's lightweight design
4. **More Power**: Showcasing the bike's performance
5. **Cool Section**: Video background featuring Bike.mp4

## Technologies Used

- HTML5
- CSS3 (with parallax effects)
- MP4 video integration
- Responsive design principles

## How to Use

1. Clone this repository
2. Open `tryhow_css_parallax_demo.html` in your web browser
3. Scroll down to experience the parallax effects
4. Watch the video background in the "COOL!" section
